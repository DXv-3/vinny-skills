# ThreeUI Reference Library

Local clone of [MengTo/threeui](https://github.com/MengTo/threeui) — 102 React components + 45 WebGL shader collections. MIT licensed.

**Location:** `~/Projects/threeui/`

## When to use this skill

- Building landing pages, hero sections, or marketing sites
- Adding WebGL/Three.js effects (particles, shaders, cursor interactions)
- Needing reference implementations for buttons, CTAs, backgrounds
- User mentions ThreeUI, MengTo, shader effects, or interactive components
- Designing anything that needs "premium feel" motion/depth

## Shader directories

All shader source lives in `src/shaders/` — each directory contains the GLSL/WebGL implementation for its corresponding component. Key shader categories:

- **Atmosphere**: `condensation`, `emerald-horizon`, `nebula`, `warp-field`, `ribbon-field`
- **Particles**: `constellation-field`, `dot-matrix`, `bell-field`, `portal-field`
- **Buttons**: `liquid-metal-button`, `shader-buttons`, `circle-buttons`, `rectangle-buttons`
- **Text**: `text-path-studies`, `typography-vortex`, `article-headings`
- **3D**: `bookshelf`, `japanese-tower`, `landscape`, `temple-night`, `sylva-living-world`
- **Data**: `data-pixel-arc`, `predictive-arc`, `performance-gauges`

## How to use in builds

1. **Reference the pattern**: Read the component source to understand the approach
2. **Adapt the shader**: Copy relevant GLSL from `src/shaders/` and modify
3. **Install if needed**: `npm install @designcodeio/threeui` for production use
4. **Style import**: `import "@designcodeio/threeui/style.css"`

## Reading source

All components are TypeScript files that export React components. Shaders are in `src/shaders/[name]/` as `.glsl` or embedded in the component files.
