# Skill Dashboard

Local-first skill inventory built 2026-08-20. Counts re-verified 2026-10-02 against SKILLS-CATALOG.json v2.1: 666 total / 612 unique (385 active / 166 archived / 115 vendor-user). Saves 120s+ per agent invocation.

## Quick Start for Agents (READ THIS FIRST)

**Do NOT run `find ... SKILL.md`** — use the prebuilt catalog (0.003s vs 120s):

```bash
cat ~/.agents/SKILLS-CATALOG.json          # 612 unique / 666 total (catalog v2.1), JSON — 0.003s
cat ~/.agents/SKILLS-CATALOG.tsv           # TSV for grep
cat ~/.agents/SKILLS-INVENTORY.md          # Markdown human view
~/bin/skills-indexer --query <term>        # e.g. --query manus, --query swiftui
~/bin/skills-indexer --cat | jq            # full JSON
~/bin/skills-indexer                       # rebuild after adding/removing skills
```

**Update after changes:** `~/bin/skills-indexer` then it auto-updates `SYSTEM-STATE.md`.
