# GitHub Ecosystem Discovery

## Purpose
Transform how you see GitHub: from "find one tool for one job" to "composable organism of living ideas." This skill discovers, evaluates, and combines repos into unified systems.

## Core Insight
1. Most people use GitHub to find ONE tool for ONE job
2. The real power is seeing GitHub as a LIVING ECOSYSTEM of composable parts
3. The weird/experimental stuff is where the real breakthroughs are

## Workflow

### Phase 1: Decompose the Problem
Before searching GitHub, break the problem into layers:

```
CAPTURE  → data ingestion, scraping, collection, monitoring
FUSE     → dedup, entity resolution, context management, linking
THINK    → memory, knowledge graphs, reasoning, semantic search
ACT      → orchestration, execution, coordination, agents
SELF     → self-healing, adaptation, learning loops
DREAM    → consolidation, subconscious, forgetting, reorganization
```

Every system has these layers. Most people only build 1-2. The breakthroughs come from connecting all 6.

### Phase 2: Search by Layer
Search GitHub separately for each layer. Use these search patterns:

**CAPTURE searches:**
- `"data ingestion" language:python sort:stars`
- `"web scraper" "AI" self-hosted`
- `"file watcher" monitor local`

**FUSE searches:**
- `"entity resolution" dedup`
- `"semantic dedup" multimodal`
- `"context management" agent`

**THINK searches:**
- `"knowledge graph" self-hosted`
- `"AI memory" local`
- `"vector database" agent`

**ACT searches:**
- `"agent orchestration" framework`
- `"multi agent" MCP`
- `"workflow engine" local`

**SELF searches:**
- `"self improving" AI`
- `"adaptive" agent framework`
- `"learning loop" autonomous`

**DREAM searches:**
- `"memory consolidation" AI`
- `"subconscious" agent`
- `"context rot" detection`
- `"dream" memory AI`

### Phase 3: Evaluate Candidates
For each repo, check:

1. **Stars** — rough popularity/quality signal
2. **Last updated** — alive or dead?
3. **Language** — does it match your stack?
4. **License** — can you use it?
5. **Dependencies** — how heavy?
6. **MCP support** — can it plug into your agent system?
7. **Local-first** — does it respect privacy?
8. **Composability** — can it be combined with other tools?

### Phase 4: Map Connections
Draw the wiring diagram:

```
[Tool A: CAPTURE] → [Tool B: FUSE] → [Tool C: THINK]
         ↓                                    ↓
[Tool D: ACT]  ← ← ← ← ← ← ← ← ← [Tool E: SELF]
         ↓
[Tool F: DREAM] → (feeds back to THINK)
```

### Phase 5: Extract and Wire
Clone the best candidates. Extract only the components you need. Wire them together with MCP or direct Python imports.

## Search Patterns That Work

| Pattern | What It Finds |
|---------|---------------|
| `"self improving" AI agent` | Adaptive systems |
| `"memory consolidation" sleep` | Dream/consolidation layers |
| `"subconscious" agent` | Forgetting as feature |
| `"context rot" detection` | Meta-cognition |
| `"Hebbian" OR "biological" memory` | Neuroscience-inspired |
| `"digital twin" personal` | Self-modeling systems |
| `"knowledge graph" "self hosted" local` | Local-first knowledge |
| `"semantic dedup" multimodal` | Data fusion |
| `"entity resolution" fuzzy` | Identity linking |
| `"dream" OR "consolidate" memory AI` | Dream consolidation |

## Anti-Patterns

- **Don't** search for "the best tool for X" — search for the LAYER
- **Don't** pick the first result — compare 5-10 candidates
- **Don't** ignore low-star repos — the weird experimental ones often have the best ideas
- **Don't** assume you need to build from scratch — someone already built 80% of what you need
- **Don't** think in terms of "tools" — think in terms of "organs" that form a living system

## Output Format
For each discovery session, produce:

1. **Layer Map** — which tools cover which layers
2. **Wiring Diagram** — how they connect
3. **Top 5 Candidates** — ranked by composability, not just stars
4. **Extraction Plan** — what to clone, what to extract, what to build
5. **Dream Layer** — what's missing that needs to be built

## Example Usage
```
"Find me the best tools to build a personal AI that watches my files,
remembers everything, connects ideas, and learns from my habits."

→ Decompose into layers
→ Search each layer
→ Map connections
→ Present wiring diagram
→ Recommend top 5 candidates per layer
```
