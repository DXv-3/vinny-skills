# CV Templates - Salary Maximization Edition

## Salary-Optimization Principles

**Your CV should signal premium-value skills and quantifiable ROI.**

### Profile Statement Template - Salary Focused

Prioritize value creation and market-demand skills:

```
Results-driven [role] with X years experience delivering measurable business impact through [high-value skill 1] and [high-value skill 2]. Expertise in [premium skill area] with proven track record of [quantified ROI statement]. Seeking to contribute at market rate for specialized skills that drive [revenue/cost savings/efficiency].
```

### Achievement Formatting - ROI Framing

Format experience bullets to show value:

**For high-paying roles (Big Tech, top startups):**
```
\cventry{Year-Year}{Senior Software Engineer}{Company}{}{}{
\begin{itemize}
  \item \textbf{ROI-focused:} Increased system efficiency by 40%, reducing cloud costs by $800K annually
  \item \textbf{Revenue impact:} Built ML pipeline that improved targeting accuracy, contributing to $2.3M incremental revenue
  \item \textbf{Scale delivery:} Led team of 5 engineers to deliver product to 500K users ahead of schedule
\end{itemize}
}
```

**For finance/fintech roles:**
```
\cventry{Year-Year}{Software Engineer}{Company}{}{}{
\begin{itemize}
  \item \textbf{Risk reduction:} Automated compliance checks saving 2000 hours/year, worth $400K
  \item \textbf{Trading advantage:} Optimized matching engine latency by 30ms, generating $1.2M/day additional profit
  \item \textbf{Regulatory delivery:} Delivered SOX-compliant system under budget by 15%
\end{itemize}
}
```

### High-Value Skill Prioritization

Rank skills by market compensation premium:

1. **Tier 1 (Premium: +30-50% pay)**
   - Large language models / LLMs
   - Generative AI / NLP
   - Cloud architecture (AWS/Azure/GCP)
   - Cybersecurity
   - Distributed systems at scale

2. **Tier 2 (Above average: +15-30% pay)**
   - Machine learning frameworks (PyTorch/TensorFlow)
   - Kubernetes/Docker
   - Data engineering (Spark, Snowflake)
   - Full-stack with modern stack

3. **Tier 3 (Baseline)**
   - Standard full-stack development
   - Traditional software engineering
   - Basic data analysis

**Structure the CV to lead with Tier 1 skills.**

### Relevance-Weighted Cutting (Salary Optimized)

When CV overflows 2 pages, cut based on:

1. **Low: Below-market roles** - Remove if irrelevant to high-paying opportunities
2. **Medium: Older experience without quantifiable impact** - Replace with numbers
3. **High: Premium skills + quantified achievements** - Keep and lead with

Cut order priority:
1. Old projects without salary-relevant skills
2. Generic responsibilities without metrics
3. Administrative tasks
4. Basic skills not in demand

**Never cut:** Skills tied to high-value compensation areas.

### Skills Section - Salary Signal Format

```
\section{Specialized Skills}
\cvitem{}{
\begin{tabular}{@{}ll@{}}
\textbf{Compensation Premium Skills:} & [LLMs, Cloud Architecture, ML Systems, Security] \\
\textbf{Market-Demand Technologies:} & [Python, React, AWS, Kubernetes, SQL] \\
\textbf{High-Impact Experience:} & [Revenue Generation, Cost Savings, Efficiency] \\
\end{tabular}
}
```

### Projects Section - For Negotiation Leverage

Projects can demonstrate value without formal employment:

```
\section{Projects}
\cvlistitem{
\textbf{[Project Name]} - [Brief description with quantified impact] \hfill [Relevant skills]\\
Revenue/cost impact: $[X] or [Y]% efficiency gain or [Z] users reached
}
```

### Cover Letter Integration Points

Key skills/achievements from CV should be referenced in cover letter:
- Revenue impact → "I built systems that generated $X in value"
- Cost savings → "My optimizations saved $Y annually"
- Scale → "Delivered solutions serving [Z] users"
